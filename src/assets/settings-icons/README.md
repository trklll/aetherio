# Iconos generales de Ajustes

Seis SVG originales de **Phosphor Icons — Fill** (licencia MIT adjunta).
No se han dibujado ni generado iconos nuevos ni modificado sus trazados.
Se presentan monocromos mediante CSS, compartidos por PC y TV.
`public/licenses/phosphor-icons.txt` conserva el aviso también en los paquetes
distribuidos, incluidos los SVG que Vite integra como data URLs.
